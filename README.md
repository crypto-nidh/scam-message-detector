# ShieldSentry - Scam Message Detector

A beautiful web application that analyzes text messages for scam patterns, suspicious keywords, and fraud indicators.

## Features

- Real-time scam detection using comprehensive keyword database
- Risk scoring system (0-100%)
- Detection of suspicious links, urgency tactics, and fraud patterns
- Beautiful responsive UI with Bootstrap 5
- Safety tips section
- Clear and intuitive interface
